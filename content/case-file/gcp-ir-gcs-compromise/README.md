# LAB SHORT · GCP IR — GCS Compromise
Kit de producción completo (nivel productor) para la serie de 5 episodios basada en el método de triage del lab LetsDefend *Google Cloud Compromise*.

## Contenido del kit
| Archivo | Qué es |
|---------|--------|
| `00_SERIES_BIBLE.md` | Marca, tono, entidades, reglas |
| `01_EPISODE_RUNDOWNS.md` | One-pager por episodio |
| `02_SHOT_LIST.md` | Planos y orden de toma |
| `03_EDIT_TIMELINE_CAPCUT.md` | Preset de edición/export |
| `04_POSTING_PACK.md` | Captions, pins, cadencia |
| `05_SET_DIAGRAM.md` | Montaje de set con tu gear |
| `06_QUERY_CHECKLIST_CTA.md` | Asset para comentarios EP05 |
| `scripts/` | Guiones palabra por palabra + captions |
| `graphics/GRAPHICS_SPEC.md` | Specs de cards/overlays |
| `broll/BROLL_SHOTLIST.md` | B-roll opcional |
| `audio/AUDIO_PLAN.md` | Mic, música, SFX |
| `checklists/` | Prod day + screen prep |

## Orden de uso (día de rodaje)
1. Lee bible + rundowns  
2. Prepara escenas de log (`checklists/SCREEN_PREP.md`)  
3. Graba cards → A-roll → screen  
4. Edita con template CapCut  
5. Publica con `04_POSTING_PACK.md`

## Serie
1. Identidad primero  
2. IP + UA  
3. Primer fail  
4. Cadena de exfil  
5. Attack → Detect

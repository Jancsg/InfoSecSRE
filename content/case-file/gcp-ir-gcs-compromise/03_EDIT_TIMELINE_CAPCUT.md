# CAPCUT / EDIT PRESET — SERIES TEMPLATE

## Project settings
- Vertical 1080x1920
- 30fps
- Frame rate match source

## Timeline layers (top → bottom)
1. Captions
2. Hero/on-screen text
3. Highlight boxes / dimmers
4. Series chip
5. A-roll face (when used)
6. Screen / B-roll
7. Music
8. SFX

## Saved styles
- Caption style: CaseFile_Captions
  - Font: mono or clean sans
  - Size ~46
  - 2–4 words/line
  - Active word color `#3DDC97`
  - Position y ≈ 1380–1450
- Title style: CaseFile_Hero
- Label style: CaseFile_MuteChip

## Default cut rhythm
- Idea change = cut
- Average hold 1.5–3.0s on screen details
- Punch-in scale 110–130% with soft ease (or hard cut crop)
- No zoom every sentence

## Color
- Screen: keep native (readable > graded)
- Face: slight contrast, true skin, no teal-orange cinema LUT heavy
- Match blacks to `#0B0F14` cards

## Export
- Codec H.264
- 1080x1920
- 8–12 Mbps preferred
- Prefer no watermark

## Episode assembly order
1. Lay VO or VO+screen sync
2. Cut picture to VO beats
3. Add hero texts
4. Add highlights
5. Captions
6. Music
7. Intro/outro cards
8. Watch muted once
9. Watch with sound once
10. Export
